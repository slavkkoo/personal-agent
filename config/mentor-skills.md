# Маппинг «тип вопроса → скилл» для PM-ментора

Бот читает отсюда строки вида `- <тип вопроса> -> <имя-скилла>` и подставляет их
в промпт — но только для скиллов, которые реально установлены в
`.claude-config/skills/<имя-скилла>/SKILL.md`. Остальные строки игнорируются.
Если не установлен ни один скилл, ментор работает на общих принципах.

Сами скиллы в репозиторий НЕ входят. Ниже — пример с именами 14 скиллов по книге
*Building Rocketships* (только имена, без содержимого). Замените на свои: любые
скиллы формата Claude Code (`SKILL.md` с frontmatter `name`/`description`).

## Маппинг

- стоит ли делать X / оценить идею -> sharp-problem-test
- новая фича в существующем продукте -> vet-a-feature
- роадмап / приоритезация бэклога -> roadmap-from-strategy
- стратегия / North Star / OKR / иерархия метрик -> vmsoop-strategy
- прайсинг / тарифы / маржа -> pricing-tier-math
- рост / growth-эксперименты / какой рычаг тянуть -> growth-lever-picker
- целевой клиент / персона / ICP -> five-dim-customer
- обратная связь клиентов / VoC / отток -> listening-machine
- проверить гипотезу / поговорить с клиентами -> customer-discovery-week
- MVP / первая версия -> slc-or-mvp
- что вырезать / онбординг слишком длинный -> scope-cutter
- активация / aha-момент / что отдать бесплатно -> aha-mapper
- триал / фримиум / конверсия в платящих -> reverse-freemium-design
- идентификаторы клиентов / аккаунты / слияние пользователей -> customer-id-architect
